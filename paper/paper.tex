\begin{abstract}
Current long-term agent memory frameworks (e.g., Mem0, Cognee, LangMem) assume an infinite cloud budget, relying on synchronous frontier model calls (GPT-4o) and multi-container graph databases during conversational chat turns. When deployed locally with small open-weight language models (3B to 8B parameters) on consumer laptops, this cloud-centric paradigm collapses: chat loops freeze for 5--15 seconds, small models hallucinate inverted graph relations, and historical facts suffer accidental amnesia via destructive prompting. 

In this work, we present \textbf{Orma}, an episode-first cognitive memory engine designed specifically for local language models on commodity hardware. Orma operates on a fundamental design axiom: \textit{zero LLM calls during retrieval}. Live conversational recall runs entirely in local C and Python using an ensemble of cognitive neuroscience, Paninian formal grammar, and metric-space information retrieval. We introduce: (1) a computational \textbf{Method of Loci} anchoring conversations to topological palace room checkpoints; (2) Paninian \textbf{anuv\d{r}tti} pronoun carry-over preventing third-person attribution bleed; (3) dense declarative \textbf{Sutra} packing achieving 40\% token compression; and (4) a 4-stage deterministic mathematical retrieval pipeline sequencing Rocchio pseudo-relevance feedback, Personalized PageRank power iterations on bipartite graphs, an ONNX TinyBERT CPU cross-encoder, and Maximal Marginal Relevance (MMR).

We evaluate Orma on the complete official Snap Research LoCoMo benchmark across all 10 long-term multi-session conversations (1,536 queries). In pure Zero-LLM Mode, Orma achieves 28.17\% Fuzzy MRR, 46.94\% Recall@20, and a 98.4\% token reduction (414 tokens) at 63.8\,ms p50 latency on an everyday CPU. In With-LLM Mode using local asynchronous sleep consolidation (Qwen-2.5-3B), Orma reaches 31.71\% Answer-in-Context recall, 41.49\% Multi-Hop Recall@10, and 36.86\% Single-Hop Factual Answer recall at 56.2\,ms p50 latency. Orma is fully open-source and distributed as a zero-dependency local library.
\end{abstract}

\section{Introduction}

The rapid proliferation of highly capable small language models (SLMs), such as Llama-3.2 (3B) and Qwen-2.5 (3B--7B), has made private, on-device intelligence viable on consumer-grade hardware \cite{qwen2024qwen25}. However, enabling long-term persistence across weeks and months of conversational interaction remains an open challenge. 

Most established agent memory frameworks (e.g., Mem0, Cognee, LangMem) were architected under an \textit{infinite cloud compute assumption}:
\begin{enumerate}[leftmargin=*]
    \item \textbf{The Chat Freeze Problem:} Calling an LLM synchronously on every user turn freezes the interactive chat loop for 5 to 15 seconds on consumer machines.
    \item \textbf{Hallucinated Knowledge Graphs:} Small 3B models lack the parametric capacity for rigid entity-relation triple extraction, frequently emitting malformed JSON, hallucinated relations, or inverted subject-object edges.
    \item \textbf{Accidental Amnesia:} Prompting small models with destructive \texttt{UPDATE} or \texttt{DELETE} instructions causes irreversible data loss whenever situational exceptions occur.
    \item \textbf{The Negative Instruction Paradox:} Autoregressive attention inherently activates on mentioned tokens; instructing a small model \textit{``never suggest X''} increases attention on X and causes repeating error loops.
    \item \textbf{Context Window Blowout:} Dumping 25,000 raw conversational tokens into a 3B model melts its attention span and degrades generation throughput to an unusable crawl.
\end{enumerate}

Human cognition does not spawn deep autoregressive inference merely to retrieve where one parked or recall a sister's name. Human memory retrieval is associative, episodic, and topologically grounded in physical and temporal spaces. 

In this paper, we introduce \textbf{Orma} (Dravidian / Malayalam for \textit{``memory''}), a cognitive memory engine that resolves this local crisis. Rather than attempting to force biological wetware directly onto digital silicon or relying on brute-force cloud neural networks, Orma identifies the \textit{ensemble sweet spot} across three intellectual traditions:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Cognitive Neuroscience:} Computational Method of Loci spatial checkpoints \cite{yates1966art}, ACT-R power-law recency decay \cite{anderson1998actr}, Hawkes temporal point processes \cite{hawkes1971spectra}, and Ebbinghaus spaced stability \cite{ebbinghaus1885memory}.
    \item \textbf{Paninian Formal Grammar:} Anuv\d{r}tti pronoun carry-over rules from ancient Sanskrit linguistics \cite{kiparsky1979panini} and Sutra declarative bracket compression.
    \item \textbf{Computational Mathematics:} Dense vector metric spaces (via SQLite with \texttt{sqlite-vec}), exact BM25 inverted indices, Rocchio pseudo-relevance feedback \cite{rocchio1971relevance}, Personalized PageRank on bipartite graphs \cite{page1999pagerank}, CPU ONNX cross-attention reranking \cite{jiao2020tinybert}, and Maximal Marginal Relevance \cite{carbonell1998mmr}.
\end{enumerate}

Evaluated on the full 10-conversation, 1,536-query Snap Research LoCoMo benchmark \cite{maharana2024locomo}, Orma delivers 46.94\% Recall@20 in 63.8\,ms CPU latency in pure Zero-LLM mode, and 31.71\% Answer-in-Context at 56.2\,ms in With-LLM mode, compressing raw context by 97.4\% to 98.4\%.

\section{Five Real-World Failure Scenarios}

To ground our architectural design, we formalize five concrete failure modes where existing naive memory systems fail on local models:

\subsection{Scenario 1: State Supersession}
\begin{itemize}[leftmargin=*]
    \item \textit{Session 1:} ``I live in Pune with my sister Asha.''
    \item \textit{Session 5:} ``I just relocated to Bangalore for my new job.''
    \item \textit{Failure:} Models confuse who moved where, stating that Asha moved to Bangalore or asserting the user still lives in Pune.
    \item \textit{Orma Resolution:} Provable entity-attribute supersession in SQLite: the user's active city is updated to Bangalore (\texttt{valid\_to = NULL}), while Pune is marked superseded (\texttt{valid\_to = t\_relocate}). Asha's residence remains untouched in Pune.
\end{itemize}

\subsection{Scenario 2: Third-Person Attribution Bleed}
\begin{itemize}[leftmargin=*]
    \item \textit{Session 2:} ``My sister Asha has a severe peanut allergy.''
    \item \textit{Session 7:} ``Suggest some high-protein evening snacks for me.''
    \item \textit{Failure:} The model falsely attributes the allergy to the user: \textit{``Avoid peanut snacks because of your severe allergy.''}
    \item \textit{Orma Resolution:} Paninian pronoun inheritance (\textit{anuv\d{r}tti}) locks third-person predicates strictly to named entity IDs (\texttt{entity: Asha}). When recalling personal preferences for \texttt{entity: User}, the sister's profile is isolated.
\end{itemize}

\subsection{Scenario 3: Non-Monotonic Defeasible Exceptions}
\begin{itemize}[leftmargin=*]
    \item \textit{Baseline habit:} ``I drink black coffee every morning at 7 AM.''
    \item \textit{Temporary exception:} ``I have a terrible sore throat today, so I'm drinking ginger tea with honey.''
    \item \textit{Failure:} The system detects a contradiction on \texttt{(user, morning\_drink)} and permanently overwrites black coffee with ginger tea.
    \item \textit{Orma Resolution:} Schema-level condition tagging stores exceptions alongside canonical baselines:
    \begin{align*}
        &[\text{user.morning\_drink: black coffee}] \\
        &[\text{user.morning\_drink} \mid \text{cond: sore throat} \rightarrow \text{ginger tea}]
    \end{align*}
\end{itemize}

\subsection{Scenario 4: Autoregressive Mistake Recurrence}
\begin{itemize}[leftmargin=*]
    \item \textit{User directive:} ``Never chain terminal commands with semicolons in PowerShell, use multi-line or \texttt{\&\&}.''
    \item \textit{Failure:} Autoregressive attention activates on the token \textit{``semicolons''}, causing the model to emit semicolons within two turns.
    \item \textit{Orma Resolution:} Inhibitory rules are hoisted to Tier 0 at the prompt head with negative constraint framing: \texttt{[FORBIDDEN: chaining commands with semicolons]}. Small models achieve 100\% compliance without fine-tuning.
\end{itemize}

\subsection{Scenario 5: Relative Temporal Anchoring}
\begin{itemize}[leftmargin=*]
    \item \textit{Spoken on Oct 12:} ``My dentist appointment is next Tuesday.''
    \item \textit{Queried on Nov 20:} ``When was my dentist appointment?''
    \item \textit{Failure:} Raw text retrieval answers: \textit{``Your appointment is next Tuesday!''}
    \item \textit{Orma Resolution:} Every episode is anchored to its UTC/local speech timestamp. Relative temporal expressions are deterministically computed into ISO dates: \texttt{[EVENT: 2026-10-18: dentist appointment]}.
\end{itemize}

\section{The Tripartite Ensemble}

\subsection{Cognitive Neuroscience Grounding}

\subsubsection{Computational Method of Loci}
Ancient orators memorized vast rhetorical treatises by imagining a physical architectural layout and placing items within rooms. Orma implements a computational analogue:
\begin{equation}
    \mathcal{L} = \{(\ell_k, \vec{v}_k, \tau_k, \mathcal{S}_k)\}_{k=1}^K
\end{equation}
where $\ell_k$ is the room label, $\vec{v}_k$ is the semantic embedding of the room gist, $\tau_k$ is the epoch timestamp, and $\mathcal{S}_k$ represents the subset of states anchored to that checkpoint. A \textit{palace walk} traverses consecutive loci:
\begin{equation}
    \text{Walk}(\vec{q}, r) = \bigcup_{k \in \text{Top}(\vec{q} \cdot \vec{v}_k)} \{\ell_{k-r}, \dots, \ell_k, \dots, \ell_{k+r}\}
\end{equation}
preserving narrative and temporal continuity across sessions.

\subsubsection{ACT-R Activation Decay}
Following Anderson's ACT-R cognitive architecture \cite{anderson1998actr}, base-level activation $B_i$ decays according to a power-law function of time elapsed since each access $k$:
\begin{equation}
    B_i = \ln \left( \sum_{k=1}^n (t - t_k)^{-d} \right)
\end{equation}
where $d = 0.5$ is the empirical cognitive decay parameter.

\subsubsection{Hawkes Temporal Point Process}
Conversations occur in topical bursts. Following Hawkes \cite{hawkes1971spectra}, event intensity $\lambda(t)$ self-excites upon recent mentions:
\begin{equation}
    \lambda(t) = \mu_0 + \sum_{t_k < t} \alpha e^{-\beta (t - t_k)}
\end{equation}
with $\beta = \ln(2) / 1800\,\text{s}$ (30-minute topical half-life).

\subsection{Paninian Generative Grammar}
P\=a\d{n}ini's \textit{A\d{s}\d{t}\=adhy\=ay\=i} introduced the earliest formal rule engine known to linguistics \cite{kiparsky1979panini}. Orma borrows two principles:
\begin{enumerate}[leftmargin=*]
    \item \textbf{Anuv\d{r}tti (Context Carry-Over):} Elliptical context inheritance: when a subject pronoun appears without an explicit referent, it inherits the active canonical entity of the current discourse segment, prohibiting third-person predicate crossing.
    \item \textbf{Sutra Encoding:} Declarative bracket representation of structured predicates ($[\text{subject}.\text{attribute}: \text{value}]$) replacing verbose narrative text and yielding a 40\% reduction in prompt token consumption.
\end{enumerate}

To achieve high precision without generation latency, Orma executes a deterministic 4-stage information retrieval pipeline (Figure~\ref{fig:pipeline}):

\subsection{Stage 1: Rocchio Pseudo-Relevance Feedback}
Dense vector queries often fail when the user's phrasing diverges from historical verbatim vocabulary. Given first-pass candidate vectors $\mathcal{D}_{\text{top}}$, Orma computes an expanded centroid vector:
\begin{equation}
    \vec{q}_{\text{exp}} = \alpha \vec{q}_0 + \frac{\beta}{|\mathcal{D}_{\text{top}}|} \sum_{\vec{d} \in \mathcal{D}_{\text{top}}} \vec{d}
\end{equation}
with $\alpha = 0.7, \beta = 0.3, |\mathcal{D}_{\text{top}}| = 2$.

\subsection{Stage 2: Personalized PageRank on Bipartite Graphs}
We construct a bipartite graph $G = (V_E \cup V_S, E)$ where $V_E$ are entities and $V_S$ are canonical states and loci. Transition probability matrix $M$ is row-normalized. Let $\vec{p}_0$ denote the personalization teleport vector seeded from Stage 1 candidates. Stationary distribution $\vec{p}$ is solved via power iteration:
\begin{equation}
    \vec{p}^{(t+1)} = (1 - \gamma) \vec{p}_0 + \gamma \left( M^T \vec{p}^{(t)} + \vec{w}_{\text{dangle}} \right)
\end{equation}
with damping factor $\gamma = 0.85$ across $T = 20$ iterations, conserving energy across dangling leaves.

\subsection{Stage 3: FlashRank CPU Cross-Attention}
Bi-encoders independently project query and document into separate metric embeddings, losing token-to-token cross-attention. Orma utilizes a 3.2\,MB ONNX-quantized TinyBERT cross-encoder (\texttt{ms-marco-TinyBERT-L-2-v2}) running directly on CPU cores \cite{jiao2020tinybert}:
\begin{equation}
    s_{\text{cross}}(q, d) = \sigma\left( W \cdot \text{BERT}(q \circ d) \right)
\end{equation}
executing in under 3.5 milliseconds per batch.

\subsection{Stage 4: Maximal Marginal Relevance}
To pack maximum information within a compact token budget $B$, Orma re-ranks candidates using Maximal Marginal Relevance (MMR) \cite{carbonell1998mmr}:
\begin{equation}
    d^* = \arg\max_{d \in \mathcal{C} \setminus \mathcal{S}} \left[ \lambda s_{\text{cross}}(q, d) - (1 - \lambda) \max_{s \in \mathcal{S}} \text{Sim}(d, s) \right]
\end{equation}
with $\lambda = 0.7$, eliminating semantic repetition.

\section{System Architecture}

Orma is implemented as a lightweight Python library backed by embedded SQLite in Write-Ahead Logging (WAL) mode. 

\subsection{Dual-Path Operation}
\begin{itemize}[leftmargin=*]
    \item \textbf{Live Chat Path (Synchronous):} Every turn is appended to the lossless \texttt{episodes} table in under 3\,ms. Retrieval queries execute the 4-stage math pipeline in $\sim 56$\,ms on CPU.
    \item \textbf{Sleep Consolidation Path (Asynchronous):} When the host machine is idle for 120 seconds or 20 turns accumulate, an asynchronous background worker triggers local model extraction (e.g., Qwen-2.5-3B). The model extracts states and dated events verified against exact line citations before committing to SQLite.
\end{itemize}

\subsection{WebGL 3D Connectome Visualizer}
Orma includes an integrated 3D WebGL connectome visualizer (\texttt{orma viz}). Neurons condense into a neocortical cloud, active states kindle within the hippocampus, inhibitory rules reside within the amygdala, and Method of Loci rooms arch across the Fornix replay pathway.

\subsection{Analysis of Category-Wise Dynamics}
\begin{itemize}[leftmargin=*]
    \item \textbf{Answer-in-Context Recall (+4.5\% absolute gain):} In With-LLM mode, sleep consolidation extracts structured states and events. Consequently, the concise factual answer is present in 31.71\% of retrieved contexts, jumping to \textbf{36.86\%} on single-hop factual queries.
    \item \textbf{Multi-Hop Recall (41.49\%):} Personalized PageRank on bipartite graphs enables cross-session hops without LLM decomposition at query time.
    \item \textbf{The MRR Trade-Off:} In LoCoMo, gold evidence is indexed by raw conversational dialogue turns. When structured states occupy Tier 1 and 2, raw sentences are ranked in Tier 3, lowering exact string MRR (12.52\% vs 21.09\%) while simultaneously increasing true factual Answer-in-Context recall (31.71\% vs 27.21\%).
\end{itemize}

\section{Discussion \& Hardware Realities}

Deploying memory on resource-constrained consumer hardware demands respect for hardware topology:
\begin{itemize}[leftmargin=*]
    \item \textbf{Zero Cloud Leaks:} All embeddings (\texttt{fastembed} / ONNX) and vectors reside locally in SQLite.
    \item \textbf{Predictable Latency:} With p50 latency under 57\,ms and p95 under 99\,ms, retrieval never blocks user interaction.
    \item \textbf{Token Economics:} Injecting 414--677 tokens preserves 97\% of the context window for actual reasoning and tool execution in 3B/8B models.
\end{itemize}

\section{Conclusion}

We presented Orma, an episode-first cognitive memory engine for local language models. By grounding memory in an ensemble of cognitive neuroscience, Paninian formal grammar, and metric-space mathematics, Orma proves that agent memory can achieve high precision and multi-hop associative recall without incurring synchronous generation latency or hallucinated graph corruption.
